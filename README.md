# Trivima Print Showcase

Mobile pages for Trivima prints (Next Big Innovation Labs), opened by scanning the QR code next to each scaffold.

- Edit the text in `build.py`, then run `python build.py` (needs `pip install qrcode[pil]`).
- `qr/` holds the QR codes (SVG + PNG); `qr-sheet.html` is an A4 sheet with each QR at 3.5 cm × 3.5 cm — print at "Actual size".
- Live site: https://saatvik-nbil.github.io/trivima-prints/
